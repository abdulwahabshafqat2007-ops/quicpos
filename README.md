# QuickPOS - Modern Point of Sale Landing Page

![CI Badge](https://github.com/abdulwahabshafqat2007-ops/QuickPOS/actions/workflows/ci.yml/badge.svg)

A professional, pixel-perfect landing page for a modern POS system with automated testing and CI/CD pipeline.

## Features

✅ **Responsive Design** - Mobile-first UI  
✅ **Hero Section** - Eye-catching headline & CTA  
✅ **Features Grid** - 4 key value propositions  
✅ **Pricing Plans** - 3-tier pricing model  
✅ **Contact Form** - With server-side validation  
✅ **Automated Tests** - 7+ PHPUnit test cases  
✅ **GitHub Actions CI/CD** - Automated checks & deployment
